## Che cos'è?

Un errore di consistenza in lettura.

## A cosa serve?

Segnala che una query lunga non riesce più a ricostruire i dati com'erano quando è partita: l'undo delle modifiche committate nel frattempo non è più protetto e, superata la retention, è stato sovrascritto.

## Codice

```sql
-- quanto resta l'undo committato, e quanto è durata la query più lunga (secondi)
SHOW PARAMETER undo_retention
SELECT MAX(maxquerylen) AS query_piu_lunga FROM v$undostat;

-- retention più lunga della query più lunga
ALTER SYSTEM SET undo_retention = 3600 SCOPE = BOTH;

-- se serve, garantita
ALTER TABLESPACE undotbs1 RETENTION GUARANTEE;
```
