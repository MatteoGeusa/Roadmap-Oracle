## Che cos'è?

Un errore: Oracle non disponibile.

## A cosa serve?

Indica che l'istanza è spenta; è tipico con la registrazione statica, dove il servizio resta noto anche a database spento.

## Codice

```bash
ps -ef | grep pmon    # nessun ora_pmon_<SID>: l'istanza è spenta
```

```sql
-- sqlplus / as sysdba
STARTUP;
```
