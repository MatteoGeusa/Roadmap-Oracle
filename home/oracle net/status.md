## Che cos'è?

Il comando `lsnrctl status [NOME]`.

## A cosa serve?

Mostra stato, avvio e uptime, il file usato (`Listener Parameter File`), il log, gli indirizzi di ascolto e i servizi. Nella diagnostica dice se il listener risponde (TNS-12541 = nessun listener).

## Codice

```bash
lsnrctl status
lsnrctl status LISTENER2
```
