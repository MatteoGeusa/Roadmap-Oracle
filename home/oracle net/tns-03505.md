## Che cos'è?

Un errore: il client non risolve l'alias.

## A cosa serve?

Indica di controllare il `tnsnames.ora`: posizione, nome del file, alias in prima colonna, `NAMES.DIRECTORY_PATH`.

## Codice

```bash
tnsping SERVIZIO_A                                   # quale sqlnet.ora usa il client
echo $TNS_ADMIN
ls -l $TNS_ADMIN/tnsnames.ora                        # il file c'è, con questo nome?
grep -n "^SERVIZIO_A" $TNS_ADMIN/tnsnames.ora        # l'alias parte dalla prima colonna?
grep -i "NAMES.DIRECTORY_PATH" $TNS_ADMIN/sqlnet.ora # TNSNAMES è tra i metodi?
```
