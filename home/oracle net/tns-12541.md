## Che cos'è?

Un errore (anche TNS-00511, Linux Error 111): nessun listener sull'indirizzo.

## A cosa serve?

Indica di controllare se il listener è avviato e se host e porta sono giusti.

## Codice

```bash
lsnrctl status                            # il listener è avviato? su quali indirizzi?
lsnrctl start                             # se non lo è
sudo ss -tlpn 'sport = :1521'             # qualcuno ascolta su quella porta?
tnsping 192.168.56.101:1521/servizio_a    # dal client: host e porta giusti?
```
