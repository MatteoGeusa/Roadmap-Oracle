## Che cos'è?

Un errore: il listener non conosce il servizio richiesto.

## A cosa serve?

Indica di controllare `lsnrctl services`, che l'istanza sia su, `local_listener`, che il servizio sia avviato e che il nome sia esatto (dominio compreso).

## Codice

```bash
lsnrctl services      # il servizio richiesto compare?
ps -ef | grep pmon    # l'istanza è su?
```

```sql
SHOW PARAMETER local_listener          -- punta a un indirizzo su cui il listener ascolta davvero?
SELECT name FROM v$active_services;    -- il servizio è avviato? il nome è esatto, dominio compreso?
ALTER SYSTEM REGISTER;                 -- forza la registrazione
```
